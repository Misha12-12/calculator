🧮 Калькулятор на Python (Tkinter)

Простой, но полностью рабочий калькулятор, написанный на Python с использованием стандартной библиотеки Tkinter. Проект демонстрирует работу с графическим интерфейсом (GUI), обработку событий и базовую логику вычислений.

Что внутри:

Графический интерфейс с кнопками и полем ввода.
Поддержка основных операций: +, -, *, /.
Обработка ошибок (деление на ноль, некорректный ввод).
Очистка экрана и вычисление результата.
Стек: Python, Tkinter.
