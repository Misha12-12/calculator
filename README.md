🧮 Python Calculator (Tkinter)

A simple yet fully functional calculator written in Python using the Tkinter standard library. The project demonstrates working with a graphical user interface (GUI), event handling, and basic calculation logic.

What's inside:

GUI with buttons and an input field.
Support for basic operations: +, -, *, /.
Error handling (division by zero, invalid input).
Clearing the screen and calculating the result.
Stack: Python, Tkinter.

🧮 Калькулятор на Python (Tkinter)

Простой, но полностью рабочий калькулятор, написанный на Python с использованием стандартной библиотеки Tkinter. Проект демонстрирует работу с графическим интерфейсом (GUI), обработку событий и базовую логику вычислений.

Что внутри:

Графический интерфейс с кнопками и полем ввода.
Поддержка основных операций: +, -, *, /.
Обработка ошибок (деление на ноль, некорректный ввод).
Очистка экрана и вычисление результата.
Стек: Python, Tkinter.
